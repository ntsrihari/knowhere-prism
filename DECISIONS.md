# Decisions (Prism v0.1)

All of these are **[REC]**: made under the owner's full-implementation authorization and open to review.

- **D-01 Contract semantics mirror Nexus.** The error codes, the pipeline order (size → strict JSON → schema name → version (R-17) → prune newer minor → structure → semantic) and the problem format `/<json-pointer>: msg`, capped at 20, all follow `knowhere-nexus/internal/contract`. Built-in wallpapers default to none (as in Nexus M1). Fonts default to the 4-key allowlist.
- **D-02 Hand-written validators, schemas as source of truth.** Ajv and JSON Schema libraries compile with `new Function` (blocked by CSP) or pull heavy JVM dependencies. Both runtimes therefore use small hand-written checkers. A Vitest suite cross-checks the TS checker against the real JSON Schemas (Ajv 2020) on every fixture plus mutations. Kotlin is held to the same fixtures.
- **D-03 Colour algorithm.** SchemeTonalSpot, spec 2021, contrast 0, matching Nexus (MCU 0.4.0). MCU 0.4.0 has extensionless ESM imports that Node cannot load, so prism-web **bundles** it with esbuild (dist is self-contained, Apache-2.0 notices kept). Vitest inlines it (`server.deps.inline`). Kotlin uses `com.materialkolor:material-color-utilities:5.0.1` with `SPEC_2021`. Parity holds on 12 seeds in both modes.
- **D-04 CSS names.** `--md-<role>` is canonical (Nexus already uses it). `--prism-<role>` is an alias, and Prism also emits Nexus's `--radius-s/m/l`, `--space` and `--font` with Nexus's formulas, so Nexus can adopt Prism without visual change.
- **D-05 Roles.** The full 49-role M3 set includes the fixed roles, `surfaceDim`/`surfaceBright` and `surfaceTint`. The spec-2025 `*Dim` roles are excluded.
- **D-06 Shape scale.** `cornerRadius` = medium, and the other steps use M3 ratios k/3 (1, 2, 4, 7). Integer half-up rounding keeps TS and Kotlin identical.
- **D-07 Density.** comfortable has scale 0, control height 40 and spacing 4/8/12/16/24/32. compact has scale -2, control height 32 and spacing 2/4/8/12/16/24.
- **D-08 Theme pack.** The fields are exactly schema, schemaVersion, id, name, version (the pack's own semver), themes[1..64] and wallpapers[0..64] (metadata only: key, name, mediaType, width, height, sha256, optional dominantColor; no bytes, no URLs). R-17 applies to the pack and to **each theme independently**, and each theme keeps its own 4 KB cap. Themes in a pack must have a `name`, unique case-insensitively (`invalid_value`). A theme's `builtin:<key>` may reference the pack's wallpapers. Duplicate wallpaper keys are `invalid_value`.
- **D-09 Kotlin.** Pure JVM with Java 17 bytecode (Android-compatible) and no Android plugin. `explicitApi()`. Strict JSON is parsed by a small own parser into kotlinx `JsonElement` (guarantees duplicate-key, depth and trailing-data rejection identical to TS and Go). The Gradle repo is Google's Maven Central mirror first, because repo.maven.apache.org returned HTTP 429 through the sandbox proxy.
- **D-10 Versions** (pinned exactly, published at least 2 weeks before 2026-11-14 unless noted): TypeScript 7.0.2, Vitest 5.0.5, Vite 8.3.5 (Vitest peer; newer patches from Nov 9 are under 2 weeks old), esbuild 0.28.2, Ajv 8.20.0, @types/node 22.20.4, MCU 0.4.0, Kotlin 2.4.20, kotlinx-serialization-json 1.12.0, JUnit 5.13.4, materialkolor MCU 5.0.1, actions/setup-java v6.2.0 (one release behind latest; its date could not be verified offline).
- **D-11 Preview.** Built with a plain esbuild script (not Vite), with no inline script or style. Dynamic colours are set via CSSOM `style.setProperty`, which CSP allows. Samples are embedded at build time, and `?theme=` only accepts same-origin relative `.json` paths.
